- **April 2026**: <strong><a class="project-link" href="https://github.com/hacherio/Categorical-CrossDoc-Democritus-Extension">Categorical CrossDoc Democritus Extension</a></strong> — Applies category theory (Kan extensions, sheaf colimits) to discover novel causal claims from research papers; a UMass CS692CT course project extending the CLIFF system.

- **April 2026**: <strong><a class="project-link" href="https://github.com/hacherio/AI-Poker-Agent">AI Poker Agent</a></strong> — Team final project (group of 4) for COMPSCI 683 (Artificial Intelligence) at UMass Amherst, tackling 2-player Limit Texas Hold'em's ~10^17-state imperfect-information game tree. Built four independent agents attacking the problem from different angles.

- **Feb. 2026**: <strong><a class="project-link" href="https://github.com/hacherio/agentic-search">Agentic Search</a></strong> — An AI-powered search app that turns a query into a structured, sourced data table; DuckDuckGo search + LLM-based schema inference and extraction.

- **July 2024**: <strong><a class="project-link" href="https://app-danger.org/">AppDanger</a></strong> — Contributed to a UMass Rescue Lab research project focused on child safety: a full-stack tool letting parents/law enforcement search for apps and see a computed "dangerousness score." The pipeline scrapes and stores reviews, then runs them through a trained NLP classification model to score review risk.

- **Feb. 2024:** <strong><a class="project-link" href="https://github.com/hacherio/UMass-Food-Review">UMass Food Review</a></strong> — A multi-microservice food review web app built for CS 426 (Scalable Web Systems), using event-bus communication with separate services for reviews, photos, and management, containerized via Docker (docker-compose for dev and prod).

- **Oct. 2023:** <strong><a class="project-link" href="https://github.com/suobset/meetu">MeetU</a></strong> — Team project for CS 326 (Web Programming) recreating When2Meet as a cleaner scheduling app. Built with Node.js/Express, Bootstrap 5, and MySQL, hosted on Heroku/AWS. Users (via Google OAuth) create events, drag-select availabilities on a group heatmap grid, vote on locations, and comment — all in a dashboard for managing past/future meetings.

- **Nov. 2021:** <strong><a class="project-link" href="https://github.com/hacherio/MoodMusic">MoodMusic — HackUMass IX Project</a></strong> — UMass Amherst Hackathon project: a Spotify-linked visual music web player. Used the Spotify API (before deprecation) to compute a song's "mood" from its audio features.

- **May 2023:** <strong><a class="project-link" href="https://github.com/hacherio/Access-Scheduler">Access Scheduler</a></strong> — CS 377 (Operating Systems) project extending the course's MLFQ scheduler with privilege and access control layered in. Written in C, built with Makefile.

- **March 2020:** <strong><a class="project-link" href="https://github.com/hacherio/RobotFRC/tree/master/frcRobot/frcRobot">FIRST Robotics Competition Project</a></strong> — Team project programming heavy-duty robots to operate through game pieces at the John D. O'Bryant High School countywide competition. Written entirely in Java.
